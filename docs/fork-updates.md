# Форк HomeNet

Задачи: ZASH-1, MIHOMO-3, XKEEN-1. Основная ветка — main.
Сохранены редактор файловых провайдеров, устройства Tailscale и выбор exit node. Основа обновлена из Zephyruso/zashboard.

`Fork release` на push в main проверяет типы и собирает dist.zip (все шрифты) и dist-cdn-fonts.zip (шрифты CDN). Релизы в x-happy-x/zashboard получают версию v3.29.1-fork.N, совпадающую с версией внутри панели, и файл sha256sums.txt. Upstream release-please с PAT и публикацией на чужом домене в форке отключён.

Проверка обновлений панели обращается к x-happy-x/zashboard, каналов Mihomo release/alpha — к последнему стабильному релизу x-happy-x/mihomo. Отдельный сторонний Smart сохраняет свой источник, поскольку это другое ядро.
Кнопка обновления панели делегирует скачивание ядру. Нужен обновлённый Mihomo этого форка или явно заданный external-ui-url:

`https://github.com/x-happy-x/zashboard/releases/latest/download/dist-cdn-fonts.zip`

В разделе провайдеров раскройте карточку: при включённом adaptive health ядра появится блок «Работоспособность». Он показывает подтверждённый режим и предположение о белых списках, результаты прямых проверок, отдельные списки обычного режима и белых списков, успешность, число проверок и детали последнего GET. Старые ядра без adaptive API продолжают работать без этого блока.

Статистика не включает проверки по кнопке обычного URL-delay: её ведёт планировщик adaptive health внутри Mihomo. История не равна текущей доступности. Панель не переключает серверы самостоятельно и не зависит от открытой вкладки: автоматический выбор выполняет fallback ядра.
